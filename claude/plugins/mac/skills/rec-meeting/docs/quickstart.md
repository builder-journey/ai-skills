# Quickstart (비전공자용)

> 개발자가 아니면 이 한 파일만 읽고 따라 해도 돼요.
> 더 자세한 검증/트러블슈팅은 `install.md`, `troubleshooting.md` 참고.

## 이게 뭐 하는 건가요?

Claude한테 **"녹음 시작해줘"** 하면 미팅을 녹음하고, **"녹음 끝"** 하면 자동으로 텍스트로 변환해주는 도구예요.
**내 목소리(마이크) + 상대방 목소리(컴퓨터에서 나는 소리)** 둘 다 한 파일에 담깁니다. Zoom, Google Meet, Discord 다 됨.

**⚠️ 사용 가능 환경:** Apple Silicon Mac 전용 (M1/M2/M3/M4). Intel Mac은 mlx-whisper 가속이 동작하지 않아 미지원.

## 왜 이렇게 복잡하게 세팅해야 하나요?

세팅 과정이 좀 길어 보이지만, 각 단계가 다 이유가 있어요. 알고 따라가면 헷갈리지 않아요.

### 1️⃣ 왜 BlackHole이라는 걸 깔아야 하나요?

**Mac은 기본적으로 "지금 스피커에서 나오는 소리"를 녹음할 수 없어요.** (저작권 보호 같은 이유)
마이크는 녹음 가능하지만, 상대방 목소리는 스피커로 나오는 소리니까 못 잡습니다.

**BlackHole**은 이걸 해결해주는 "가상 마이크"예요.
- 컴퓨터 스피커로 나가던 소리를 → 마치 마이크에 들어온 것처럼 흉내 내줍니다
- 그러면 녹음 프로그램(ffmpeg)이 상대방 목소리도 녹음할 수 있게 돼요

> 비유: 스피커 앞에 마이크를 갖다 대는 걸, 케이블로 깔끔하게 해주는 거라고 보면 돼요.

### 2️⃣ 왜 Audio MIDI Setup에서 "Multi-Output Device"를 만들어야 하나요?

문제: BlackHole로만 소리를 보내면 **나는 소리를 못 들어요**. (BlackHole은 가상이라 실제 스피커가 아님)
미팅 중인데 상대 말이 안 들리면 망하잖아요.

**해결: 소리를 두 군데로 동시에 보내면 됨.**
- 진짜 스피커 → 내가 듣고
- BlackHole → 녹음 프로그램이 잡고

이걸 동시에 해주는 게 **Multi-Output Device**예요. Mac에 기본으로 들어있는 "Audio MIDI Setup" 앱에서 만들 수 있어요.

> 비유: 헤드폰 단자에 분배기 끼워서 2명이 같은 노래 듣는 거랑 같음.

### 3️⃣ 왜 "Master Device를 BlackHole로" 설정해야 하나요? (가장 헷갈리는 부분)

크롬(구글 미트)은 까칠해서 Multi-Output Device한테 소리를 줄 때 **"Master로 지정된 장치한테만"** 줍니다.
Master가 스피커면? → 스피커에만 소리 가고 BlackHole은 빈손 → **상대 목소리 녹음 안 됨**.

그래서 Master를 일부러 **BlackHole**로 지정합니다.
- 크롬이 BlackHole에 소리를 보내면
- Multi-Output이 그걸 스피커에도 자동으로 복사해줘서 → 나도 듣고 녹음도 됨

(Drift Correction은 두 장치 사이 미세한 시간차 보정인데, Master가 아닌 쪽에만 켜는 게 원칙. 그냥 시키는 대로 체크하면 됨)

### 4️⃣ 왜 5분씩 잘라서 녹음하고 텍스트 변환하나요?

만약 1시간짜리 미팅을 녹음 끝나고 한꺼번에 텍스트로 변환하면 → **녹음 끝나고 5~10분 더 기다려야 해요.**

대신 5분 단위로 토막내서 저장하면, **녹음 진행 중에 백그라운드에서 미리미리 텍스트로 변환**해둘 수 있어요.
미팅이 끝나는 순간엔 마지막 5분 조각만 처리하면 끝 → **거의 즉시 텍스트가 나옵니다.**

> 비유: 식사 끝나고 설거지 한 번에 하지 말고, 다 먹은 접시부터 미리 닦아두는 식.

마지막에는 토막들이 하나의 파일(`meeting-XXXX.m4a`)과 하나의 텍스트(`meeting-XXXX.txt`)로 자동으로 합쳐집니다. 중간 토막 파일은 알아서 지워져요.

### 5️⃣ whisper, mlx-whisper는 뭔가요?

**Whisper**는 OpenAI가 만든 "오디오를 텍스트로 변환하는 AI 모델"이에요.
**mlx-whisper**는 그걸 **애플 실리콘(M1/M2/M3 Mac)에 최적화한 버전**. 같은 작업을 일반 whisper보다 5~10배 빠르게 합니다.

서버에 안 올리고 **내 Mac에서 바로 처리**하기 때문에 미팅 내용이 외부로 나가지 않아요. (프라이버시 OK)

## 진짜 사용은 이게 전부

세팅 끝나면 평생 다음 두 마디만 쓰면 돼요:

- 시작할 때: **"녹음 시작해줘"**
- 끝낼 때: **"녹음 끝"**

녹음 끝나면 텍스트 파일이 자동으로 TextEdit에 떠요. 파일은 `~/meeting-log/` 폴더에 저장됨.

## 세팅 다 됐는지 한 번에 확인하기

설치를 다 했다면 아래 한 줄만 터미널에 복사해서 실행하면 9가지 항목을 한꺼번에 점검해줘요:

```bash
REC_DIR=$(find ~/.claude/plugins/cache -type d -name rec-meeting | head -1)
"$REC_DIR"/check-setup.sh
```

✅가 다 뜨면 사용 준비 완료. ❌ 항목이 있으면 그 줄 아래 화살표(→)에 적힌 명령어를 따라하면 돼요.

## ⚠️ 첫 녹음 시 권한 팝업 (꼭 읽기)

처음 **"녹음 시작해줘"** 했을 때, macOS가 두 번 정도 팝업을 띄워요:

1. 🎤 **"마이크 사용 권한"** → **"허용"** 클릭
2. 🖥 **"시스템 오디오 녹음 권한"** (BlackHole 통해 들어옴) → **"허용"** 클릭

만약 실수로 **"허용 안 함"**을 눌렀다면:
- **시스템 설정 → 개인정보 보호 및 보안 → 마이크** 에서 `ffmpeg` 또는 `Terminal`(`iTerm`/사용 중인 터미널) 항목을 켜주세요.
- macOS Sequoia(15+)는 **화면 녹화** 권한도 추가로 요구할 수 있음. 같은 화면에서 토글.
- 안 켜져 있으면 녹음 파일이 무음으로 저장됩니다.

## 자동 보호 기능

이 스킬은 사고를 막아주는 보호 장치가 내장돼 있어요.

### 🔔 알림 (자동)

- **시작/종료**: 알림 + 소리
- **15/30/45분 경과**: 짧은 진행 알림 (무음)
- **60분부터 30분 단위**: "계속 녹음할까요?" 알림 (소리) — 깜빡 잊고 녹음 켠 채 두는 사고 방지

### 💤 슬립 방지 (자동)

녹음 중에는 **Mac이 자동 슬립에 들어가지 않습니다** (`caffeinate -i`). 디스플레이는 평소처럼 꺼져도 OK.

### 🛟 비정상 종료 자동 복구 (자동)

| 상황 | 어떻게 되나? |
|---|---|
| **"녹음 끝" 안 하고 Claude를 닫음** | ffmpeg는 백그라운드에서 계속 녹음. 다음에 Claude 켜고 "녹음 끝"만 말하면 정상 마무리. |
| **노트북 그냥 닫음 / 슬립** | `caffeinate` 덕분에 슬립 방지 → 녹음 계속. |
| **PC 종료 / 강제 재부팅** | 다음 번 녹음 시작 시 자동 감지: "⚠️ 이전 비정상 종료된 세션 발견. 자동 복구 중..." → 남아있던 세그먼트 자동 합본/전사 → 새 녹음 시작 |
| **출력 장치가 묶인 채 남음** | 다음 번 `rec-start.sh` 호출 시 자동 복구. 즉시 풀고 싶으면 `시스템 설정 → 사운드`에서 수동 변경. |

즉, **"녹음 끝" 못 하고 어떤 사고가 나도 데이터는 잃지 않습니다.**

## 환경 변수로 커스터마이즈 (선택)

대부분 안 건드려도 됨. 필요한 사람만 `~/.zshrc` 등에 추가:

```bash
# Multi-Output Device 이름을 바꿨다면
export REC_MULTI_OUTPUT_NAME="내 이름"

# 세그먼트 길이 변경 (기본 300초 = 5분)
export REC_SEGMENT_SECONDS=180

# 녹음 보관 기간 (기본 0=영구). 7일 이상 된 합본 자동 삭제
export REC_RETENTION_DAYS=7

# 알림 비활성화 (심야 작업용)
export REC_NO_NOTIFY=1

# 트랜스크립션 언어 (기본 ko, "auto" = 자동 감지, "en" = 영어 등)
export REC_LANG=auto
```
